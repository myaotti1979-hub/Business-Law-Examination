## 機能

- 📖 学習テキスト（全85セクション・ひっかけポイント付き）
- 📝 演習（15問ランダム / 全問 / 弱点集中）
- 🎯 模擬試験（本試験完全準拠・一括採点方式）
- 📊 分析ダッシュボード
- 📜 条文辞典（六法）
- 🤖 AI添削（1級論述/Gemini API）
- 📱 PWA対応（オフライン学習可能）

## デプロイ

GitHub Pagesで公開。Settings → Pages → Source: main branch。

JSONファイルは必ず `data/` フォルダ内に配置。

## 技術仕様

- Vanilla JS（フレームワーク不使用）
- Service Worker: HTML/JSONはネットワーク優先
- APP_VER: v81 / SWキャッシュ: houmu-v81
- 問題形式: single（4択）/ marubatsu（○×8択）/ scenario（事例）
